## Quick Start

```bash
git clone https://github.com/ronakraval104-sys/Gaya-Agent.git
cd Gaya-Agent

# Open either dashboard in your browser
open skills-dashboard.html
open agent-methodology-dashboard.html
```

No build step needed. Zero dependencies.

## Dashboards

### ⚔ Agent Methodology Dashboard
Command center with 5 agent cards (Gaya, LOGOS, Tvashtar, Freya, Default) — methodology, timing stats, and token tracking per session.

### 📚 Skill Catalog
Interactive card grid of all 37 Gaya skills — 21 custom + 14 Superpowers + 2 bonus. Filter by category, search by name/description/tags, click to expand workflow examples and related skills.
