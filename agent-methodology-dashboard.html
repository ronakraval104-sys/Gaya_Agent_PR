Ponytail's Ladder : The Decision Engine

YAGNI · Deletion Over Addition

"The best code is the code never written." Before writing any code, climb the 7-rung ladder from top to bottom:

RUNG 01

Exist at all?

Skip it completely (YAGNI). Eliminate unnecessary complexity.

RUNG 02

Already here?

Reuse existing modules. Don't rewrite what already exists.

RUNG 03

Standard library?

Use built-in language primitives and stdlib tools.

RUNG 04

Native OS / platform?

Use native platform features (e.g. native HTML date inputs, OS commands).

RUNG 05

Installed dependency?

Use packages already in package.json or requirements.txt.

RUNG 06

One line?

Express cleanly in a single concise line.

RUNG 07

Minimum code

Write only the smallest working implementation that passes.
