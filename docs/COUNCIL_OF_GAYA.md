# 🏛️ Council of Gaya — Live Telemetry & Mission Dashboard

The **Council of Gaya Dashboard** is an enterprise-grade Next.js command center that visualizes agent telemetry, real-time knowledge graphs, subagent execution states, and system health.

---

## ⚡ Key Capabilities
- **Live Antigravity & Gaya Sync**: Hooks directly into active session transcripts to display live agent thinking, active tool executions, tokens in/out, and security gates.
- **Seat Roster Telemetry**: Visualizes the 4 Core Council Seats:
  - 🛡️ **LOGOS** (Mind / QC Gate)
  - 🔨 **Bob** (Hands / Precision Builder)
  - 🎨 **Freya** (Heart / Polymath Designer)
  - 🦾 **Tvashtar** (Craftsman / REA Engine)
- **Knowledge Core & Graph**: Visualizes memory, lessons learned, and skill relationships in real time.
- **Live Connectors**: Monitored integrations for Antigravity, ComfyUI, GPU/VRAM, Mini Gaya, and GitHub.

---

## 🚀 Installation & Launch

### Prerequisites:
- Node.js 18+ (Node 20+ recommended)
- npm or pnpm

### Quick Launch:
```bash
cd council_of_gaya
npm install
npm run dev -p 4200
```
Or on Windows, simply double-click:
```cmd
council_of_gaya\start_council.bat
```

Access the dashboard at:
👉 **`http://localhost:4200`**
